End-to-end CNN inference accelerator for **face mask detection**, deployed on a **PYNQ-Z2 (Zynq-7020) FPGA**. A custom CNN trained in Keras is compiled through the Tensil ML compiler into a systolic-array hardware accelerator, integrated in a Vivado block design, and executed from a PYNQ Jupyter notebook achieving **~98% inference accuracy** — matching the ResNet-50 reference while fitting in 31% BRAM and running ~3× faster than CPU.

## System Architecture

### End-to-End Pipeline

```
 Kaggle Face-Mask Dataset (12k images)
         │
         ▼
 ┌─────────────────────────────┐
 │  Custom CNN  (Keras)        │  3 Conv layers, 64×64 input
 │  Input: 64×64×3             │  MaxPool, Dense, Softmax
 │  Output: [mask, no_mask]    │  Training acc: ~99%, Test acc: ~98%
 └────────────┬────────────────┘
              │  SavedModel (no sigmoid in graph)
              ▼
 ┌─────────────────────────────┐
 │  tf2onnx export             │  opset 10  (Tensil-compatible)
 │  → maskmodel_*.onnx         │
 └────────────┬────────────────┘
              │
              ▼
 ┌─────────────────────────────┐
 │  Tensil compiler            │  docker: tensilai/tensil
 │  -a pynqz1.tarch            │  Systolic array: 8×8 MACs, FP16BP8
 │  → tmodel / tdata / tprog   │  Lowers ONNX ops to array instructions
 └────────────┬────────────────┘
              │
              ▼
 ┌─────────────────────────────┐
 │  Tensil RTL generator       │  tensil rtl -a pynqz1.tarch
 │  → top_pynqz1.v             │  Systolic array + BRAM weight store
 │  → bram_dp_128x8192.v       │
 │  → bram_dp_128x2048.v       │
 └────────────┬────────────────┘
              │
              ▼
 ┌─────────────────────────────┐
 │  Vivado Block Design        │  Zynq-7020 (XC7Z020-1CLG400C)
 │  PS7 ← M_AXI_GP0 (ctrl)    │  AXI-DMA (MM2S): instructions → accel
 │  PS7 ← S_AXI_HP0/1/2(data) │  4× SmartConnect for AXI routing
 │  AXI-Stream → top_pynqz1   │  Generate bitstream → .bit file
 └────────────┬────────────────┘
              │
              ▼
 ┌─────────────────────────────┐
 │  PYNQ Jupyter Notebook      │  Load .bit + .hwh overlay
 │  Python driver              │  Copy .tmodel/.tdata/.tprog to board
 │  FPGA inference             │  Run classification → ~98% accuracy
 └─────────────────────────────┘
```

### Vivado Block Design — IP Connections

```
Zynq PS7
 ├── M_AXI_GP0  ──► SmartConnect_0 ──► AXI-DMA (S_AXI_LITE, control)
 ├── S_AXI_HP0  ◄── SmartConnect_1 ◄── AXI-DMA (M_AXI_MM2S, read instructions)
 ├── S_AXI_HP1  ◄── SmartConnect_2 ◄── top_pynqz1_0 (M_AXI, read weights/DRAM)
 └── S_AXI_HP2  ◄── SmartConnect_3 ◄── top_pynqz1_0 (M_AXI, write outputs)

AXI-DMA (MM2S)
 └── M_AXIS_MM2S ──► top_pynqz1_0.s_axis_instruction
                     (streams compiled tprog instructions to systolic array)

RST_PS7_0_50M ──► aresetn for DMA + SmartConnects + accelerator
```

## CNN Architecture

### Model (Final — 64×64 Input)

```
Input:  64 × 64 × 3  (RGB)
│
├── Conv2D(32, 3×3, ReLU) → MaxPool2D(2×2)   → 32 × 31 × 31
├── Conv2D(64, 3×3, ReLU) → MaxPool2D(2×2)   → 64 × 14 × 14
├── Conv2D(128, 3×3, ReLU) → MaxPool2D(2×2)  → 128 × 6 × 6
├── Flatten → Dense(256, ReLU)
└── Dense(2)  ← Softmax applied at inference time outside graph
    [with_mask, without_mask]
```

> **Important:** The Softmax is applied in Python after FPGA inference — it is **not** in the ONNX graph. This prevents Tensil compiler issues with Softmax lowering.

### Why 64×64 and Not 128×128?

| Metric | 128×128 model | 64×64 model |
|---|---|---|
| MACs | ~4.6× more | baseline |
| Execution stages (tprog) | ~3.6× more | baseline |
| DRAM traffic | ~4× more | baseline |
| FP16BP8 quantization error | accumulates | bounded |
| FPGA accuracy | 85–88% | **~98%** |

The key insight: more computation means more accumulated quantization error in FP16BP8 (16-bit float with 8-bit exponent). Smaller input → fewer MACs → less error → accuracy matches the 128×128 software model.

## How to Reproduce

### Step 1 — Train the CNN

```python
# In Jupyter or Python script
model = Sequential([
    Conv2D(32, (3,3), activation='relu', input_shape=(64,64,3)),
    MaxPool2D(2,2),
    Conv2D(64, (3,3), activation='relu'),
    MaxPool2D(2,2),
    Conv2D(128, (3,3), activation='relu'),
    MaxPool2D(2,2),
    Flatten(),
    Dense(256, activation='relu'),
    Dense(2)   # No Softmax in model — apply at inference time
])
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
model.fit(train_ds, epochs=20, validation_data=val_ds)
model.save('saved_model_format_nosig_arch')
```

### Step 2 — Export to ONNX

```bash
python3.10 -m venv my_project_venv && source my_project_venv/bin/activate
pip install tf2onnx
python -m tf2onnx.convert \
    --saved-model saved_model_format_nosig_arch \
    --output maskmodel_pynqz1.onnx \
    --opset 10
```

### Step 3 — Compile with Tensil

```bash
docker pull tensilai/tensil
docker run -it -v $(pwd)/models:/workspace tensilai/tensil bash
# Inside container:
tensil compile \
    -a /demo/arch/pynqz1.tarch \
    -m /workspace/maskmodel_pynqz1.onnx \
    -o output_0
# Produces: output_0.tmodel, output_0.tdata, output_0.tprog
```

### Step 4 — Generate RTL

```bash
# Inside Tensil container:
tensil rtl -a /demo/arch/pynqz1.tarch -s true
# Produces: top_pynqz1.v, bram_dp_128x8192.v, bram_dp_128x2048.v
```

### Step 5 — Vivado Block Design

1. Open `hardware/mask_detection.xpr` in Vivado 2022.2
2. Open the `tensil_pynqz2` block design
3. Verify connections: PS7 → SmartConnects → AXI-DMA → top_pynqz1_0
4. **Generate bitstream** → `tensil_pynqz2_wrapper.bit`
5. **Export hardware** → `.hwh` file

### Step 6 — Deploy on PYNQ

```bash
# Copy to PYNQ board over SSH/Jupyter upload:
scp tensil_pynqz2_wrapper.bit xilinx@pynq:/home/xilinx/
scp tensil_pynqz2.hwh         xilinx@pynq:/home/xilinx/
scp output_0.tmodel output_0.tdata output_0.tprog xilinx@pynq:/home/xilinx/
```

```python
# In PYNQ Jupyter notebook:
from pynq import Overlay
import numpy as np

overlay = Overlay("tensil_pynqz2_wrapper.bit")
# Load tmodel, feed test image, run inference
# Apply softmax to output logits
# result = np.argmax(softmax(logits))  → 0=with_mask, 1=without_mask
```

## Tensil Architecture Config (`pynqz1.tarch`)

```json
{
  "data_type": "FP16BP8",
  "array_size": 8,
  "dram0_depth": 1048576,
  "dram1_depth": 1048576,
  "local_depth": 8192,
  "accumulator_depth": 2048,
  "simd_registers_depth": 1,
  "stride0_depth": 8,
  "stride1_depth": 8
}
```

- **FP16BP8:** 16-bit floating point, 8-bit exponent — hardware-friendly quantization
- **8×8 systolic array:** 64 MAC units operating in parallel per clock cycle
- **local_depth 8192:** on-chip scratchpad BRAM for activations
- **accumulator_depth 2048:** on-chip accumulator BRAM for partial sums
